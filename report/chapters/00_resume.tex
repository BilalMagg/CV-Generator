\chapter*{Résumé}
\addcontentsline{toc}{chapter}{Résumé}

Ce projet présente la conception et le développement de \projectname{}, une plateforme web intelligente de génération de CV assistée par intelligence artificielle. L'application permet aux utilisateurs de générer un curriculum vitae personnalisé et optimisé pour une offre d'emploi spécifique en quelques secondes. Le système repose sur une architecture en microservices combinant Angular pour le frontend, ASP.NET Core pour les services backend, et une pipeline d'agents IA en Python utilisant LangChain et LangGraph pour l'extraction, l'analyse, l'optimisation et la livraison des CV. L'infrastructure est entièrement conteneurisée avec Docker et déployée via un pipeline CI/CD complet intégrant des outils de sécurité et de qualité (SonarCloud, Trivy, OWASP ZAP). Le projet a été réalisé par une équipe de six développeurs fullstack selon une méthodologie SCRUM adaptée.

\vspace{0.5cm}
\textbf{Mots-clés :} Génération de CV, Intelligence Artificielle, Microservices, Angular, ASP.NET Core, LangChain, Docker, DevSecOps.

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This project presents the design and development of \projectname{}, an intelligent web platform for AI-powered CV generation. The application enables users to generate a tailored and optimized curriculum vitae for a specific job offer in seconds. The system is built on a microservices architecture combining Angular for the frontend, ASP.NET Core for backend services, and a Python AI agent pipeline using LangChain and LangGraph for extraction, analysis, optimization, and delivery of CVs. The infrastructure is fully containerized with Docker and deployed through a complete CI/CD pipeline integrating security and quality tools (SonarCloud, Trivy, OWASP ZAP). The project was carried out by a team of six full-stack developers following an adapted SCRUM methodology.

\vspace{0.5cm}
\textbf{Keywords:} CV Generation, Artificial Intelligence, Microservices, Angular, ASP.NET Core, LangChain, Docker, DevSecOps.
